Activity Manager @VERSION@ (Gestione attività) - Windows-style task manager for Linux (KDE Plasma 6, Wayland)

Install (into your home directory, no sudo needed):
  ./install.sh

Ctrl+Alt+Del    security screen (Lock, Switch user, Sign out, Task Manager)
Ctrl+Shift+Esc  Activity Manager

Update: from Settings → Updates in the app, or run
  gestione-attivita --update

Uninstall:
  ./uninstall.sh

The interface is in English and Italian; it follows the system language
and can be changed in Settings.

Required libraries (Arch/CachyOS): webkit2gtk-4.1 gtk3 libayatana-appindicator libnotify
Other distributions and details: https://github.com/giannoccarol/Activity-manager-linux
